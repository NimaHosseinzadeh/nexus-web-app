## ✨ Features

- 🎨 **Modern & Clean UI**: Perfectly balanced layout using Flexbox, CSS Grid, and custom positioning.
- 📱 **Mobile-First Responsive Navigation**: Accordion-style mobile menu designed for optimal touch experience.
- 🌙 **Dark Mode Support**: Seamless dark theme adaptation for comfortable night viewing.
- 🎯 **Pixel-Perfect Centered Logo**: Centered desktop & mobile branding without breaking layout flow.
- ⚡ **Pure & Lightweight**: Clean architecture without heavy external frameworks.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic elements and accessible markup.
- **CSS3**: Media queries, CSS variables, and modern layout techniques.
- **Remix Icon / FontAwesome**: Vector icons for clean UI visuals.
